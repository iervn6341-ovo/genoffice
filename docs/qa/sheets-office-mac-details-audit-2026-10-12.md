## 判讀方式與限制

證據分成五類：**nativeUI**（Mac Excel 實機）、**officialMac**（Microsoft 官方且適用 Mac 的文件）、**source**（目前介面／流程程式碼）、**實測**（GenOffice UI 操作）、**save/reopen**（GenOffice UI 寫入檔案後關閉重開）；另有 **engine/unit**（模型或 OOXML gateway 測試）。這些證據不能互相替代。以下分別標出實測到的狀態與尚未驗證的部分。

Excel 的原生深入操作在資料驗證面板開啟後卡住，後續 UI accessibility 查詢逾時。只確認 Data Validation 面板有 **Settings / Input Message / Error Alert** 三分頁；當下控制項停用，停用原因未判定，沒有取得實際可編輯規則的細項。**不要把面板分頁存在寫成完整操作驗證。** Excel 原生六分頁「儲存格格式」、四分頁「頁面設定」、自訂頁首／頁尾及「資料剖析」三步驟，已在本次前的原生會話成功檢視；沿用 handoff 證據，不標成未取得。

### Data Validation

**證據：nativeUI（只到 tabs）+ officialMac + source + engine/unit + GenOffice UI 實測 save/reopen。Excel for Mac 開檔未驗。**

- **原生步驟／實際：** 空白 Book1 → Data → Data Validation；視窗有 Settings、Input Message、Error Alert 三頁；當下控制項停用，原因未判定，之後的 UI accessibility 查詢逾時。無法證明每種限制選項在此 UI 的行為。
- **官方 Mac 基準：** Microsoft「[Apply data validation to cells](https://support.microsoft.com/en-au/excel/get-started/apply-data-validation-to-cells)」適用範圍包含 Excel for Microsoft 365 for Mac，說明三頁分別設限制／輸入提示／錯誤警示。這是 Mac 適用的官方說明，不是本機操作證據。
  **GenOffice UI-authored list mapping defect — P1，已確認（Excel 開檔尚未驗）：**

- **步驟：** scratch workbook 選取 B2:B4 → Data → Data Validation → Add Rule → Type = Dropdown → Add 兩列 `Open`、`Closed` → Done；查看 live rule、存檔、關閉並重開。
- **GenOffice 實際：** 面板作者流程成功，live `formula1` 為 `JSON.stringify(["Open", "Closed"])`；save/reopen 後 rule 仍為 list，範圍仍為 B2:B4。UI source 同樣以 `serializeListOptions(finalList.map(item => item.label))` 序列化選項（`node_modules/@univerjs/sheets-data-validation-ui/lib/es/index.js:2189`）。Gateway [`xlsx-dv.ts:232–243`](</Volumes/Kingston NV2/Program_workspace/swift_workspace/genoffice/packages/xlsx-gateway/src/gateway/xlsx-dv.ts:232>) 對非 `=` 清單值直接加引號；輸出 `<formula1>"["Open","Closed"]"</formula1>`，保留 JSON 文字而未轉為 CSV 清單 literal。
- **預期：** Excel list validation 的 Formula1 應為逗號分隔清單或工作表參照；官方來源：[Excel.Validation.Add](https://learn.microsoft.com/en-us/office/vba/api/excel.validation.add)、[Excel JavaScript data validation](https://learn.microsoft.com/en-us/office/dev/add-ins/excel/excel-add-ins-data-validation)。直接清單預期 `<formula1>"Open,Closed"</formula1>`。從 GenOffice 重開可保留該模型不等於 Excel 開啟後下拉／規則可用；Excel for Mac 開檔結果尚未驗證。
- **來源／引擎探針：** `univerAPI.newDataValidation().requireValueInList(['Open','Closed'], ...)` 的 model-probe 也得到相同 JSON → quoted literal 輸出；它是額外 exporter probe，不代替 UI-authored case。`xlsx-dv` unit tests 通過現有序列化規則，不代表此格式與 Excel list literal 相容。
