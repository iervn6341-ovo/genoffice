# Sheets formula cache refresh — 2026-10-13

An imported formula can recalculate correctly in the live grid after a precedent edit while the saved XLSX retains its old `<v>` cache. The edit journal only contains the changed precedent and formulas authored this session, so the save request previously omitted every unedited imported formula result. `fullCalcOnLoad="1"` asks Excel to repair this later but does not make the saved workbook correct for other readers.

The save path now forces and awaits a Univer formula result-application pass, then reads the indexed imported formula cells from the live model and includes their results as formula cache updates. This runs for fully preloaded workbooks and for streamed workbooks whose bounded dependency closure is active. It requires unchanged coordinates, automatic calculation, and a matching formula source in the model. Content edits to a formula cell remain owned by the existing journaled-formula path; style-only edits do not suppress its cache update. The XLSX gateway keeps the original `<f>` and changes only its cached `<v>`.

Cells that have no computed result, a changed formula source, or an unsupported-engine result are not sent as refreshed caches. In particular, a file-cached display value shown over an engine error is not mistaken for a new calculation. A calculation timeout blocks the normal save with a localized retry message rather than writing known-stale caches; crash recovery remains best-effort. The existing engine budget/unsupported-formula limitation remains: if a streamed workbook cannot activate a closure, its cached values may remain stale until Excel recalculates on open. Manual calculation preserves the user's choice and does not force a save-time pass.

The display fallback now follows explicit cross-sheet references and indexed formula chains to check whether an edited cell is a precedent. Sheet qualifiers resolve case-insensitively, including quoted names. A cross-sheet precedent change can produce a genuine error such as `#DIV/0!`; the old cached number must not mask that result merely because the formula's own sheet has no edits. An unrelated-sheet edit still leaves the imported cache visible, and the unsupported `#NAME?` capability fallback remains intact. Point references use direct map lookups, and a workbook with no content edits skips the dependency walk. Traversal is bounded at 1,000 formulas or 10,000 range-index entries to protect painting from pathological chains; reaching either bound conservatively exposes the engine result, which can show a capability error instead of the file cache until the workbook is reopened.

Univer represents some boolean formula results as model `v: 0|1` with `t: BOOLEAN`. The cell reader now reports their typed boolean value, so a refreshed cache retains XLSX `t="b"` rather than changing type to a number.

Focused verification: save-request plus XLSX XML regression for preloaded and closure-active modes; timeout refusal before any save IPC; typed boolean formula reader/cache regression; direct/transitive cross-sheet and unrelated edit fallback cases; existing journaled formula/recovery tests. Sheets TypeScript check and targeted ESLint passed. Rebuilt Electron UI and full-process reopen verification are owned by root QA.

Root's full-process closure-mode verification passed all 11 formula/cache/type cases over three saves and four opens when cross-sheet references used the sheet's stored casing. Its lowercase `inputs!A1` variant exposed a separate Univer 0.25.1 issue: the engine uses exact-case lookups for both its formula sheet-name map and workbook worksheet lookup, so a valid Excel reference initially evaluates as `#VALUE!`. Sheets now installs an exact-first, case-insensitive fallback at those two runtime lookup boundaries when loading a workbook. The original `<f>` formula text and sheet-name maps remain unchanged. Targeted lookup tests cover mixed case, quoted-name apostrophes, exact priority, and idempotent installation; root owns the rebuilt UI/full-process validation of the lowercase variant.

Final rebuilt-app acceptance completed: both M5000 active-closure and M2000 full-formula cases passed, with 11 formulas, three saves and three full-process reopens, including lowercase sheet references and immediate saves. The formula-symbol regression also passed (11.8 s); untouched D1 now saves cache 8 after its precedent changes.
