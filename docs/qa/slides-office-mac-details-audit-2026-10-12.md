## 優先差異

### P1：頁首及頁尾重新開啟會改變日期語意，也不能只套用目前投影片

**Office 預期與證據。** [Office UI] 原生對話框分「投影片」及「備忘稿與講義」兩頁；投影片日期可選自動更新並從格式清單挑選，或選固定值；另有投影片編號、頁尾、標題投影片不顯示、預覽、套用目前投影片及全部套用。備忘稿／講義另有頁首、頁尾、日期及頁碼。[官方 Mac] 說明投影片不支援頁首，但備忘稿／講義可有頁首及頁尾；自動日期與固定日期是不同模式， footer placeholder 可在投影片母片調整位置和樣式。[官方 Mac 說明](https://support.microsoft.com/en-us/powerpoint/add-page-numbers-date-and-time-or-footer-text-to-all-slides-in-powerpoint-for-mac)、[母片格式說明](https://support.microsoft.com/en-us/powerpoint/change-footer-formatting-on-all-slides-in-powerpoint-for-mac)。

**GenOffice 實際行為。** [程式碼] 對話框只有日期核取方塊、一個「自動更新」核取方塊與日期文字欄；每次開啟都把 `dateAuto` 設成 `true`。`getHeaderFooter`／`readHeaderFooter` 只回傳日期字串、頁尾文字與頁碼狀態，沒有回傳欄位是否為固定日期，因此先前保存的固定日期會在重新開啟時被誤認為自動日期；再次套用後會寫成 `datetime1` 動態欄位。介面只有「套用至全部」，IPC 沒帶目前投影片索引。引擎雖接受可選 `slideIndexes`，但 renderer、shared IPC 及 main handler 沒有傳遞它。現有套用動作會移除該投影片自己的 `dt`、`ftr`、`sldNum` placeholder 後，以固定底部座標、12pt、`898989` 重建；這會覆蓋既有 placeholder 的版面與字型格式。現況也沒有備忘稿／講義頁籤、固定／自動單選、日期格式清單、標題投影片排除及預覽。

**存檔重開。** [round-trip] `packages/pptx-engine/tests/insert-extended.test.ts` 的 `applyHeaderFooter` 兩個既有測試通過：基本欄位會存檔重開，重套時不重複 placeholder。它們沒有涵蓋 UI 日期模式回填、套用範圍、母片格式保留。新增 GenOffice Electron E2E 已實際完成固定日期 UI → 保存 → 關閉 → 重開 → 對話框 → Apply to All → 保存：重開後固定日期仍顯示，但 Auto Update 被勾選；再套用後兩頁都變成 `datetime1` 動態欄位。這確認了 `getHeaderFooter` 缺少日期模式欄位與 dialog 預設值造成的回填問題；Apply to All 的保存結果也有 XML 證據。

**實作驗收。** 固定日期存檔重開後仍勾選「固定」並保留原字串；自動日期存檔重開後仍為動態欄位且格式選項回填正確。Apply 只改目前投影片，Apply to All 才改全簡報；兩者都保留原母片／版面位置、字級、顏色和動畫，不重建樣式。備忘稿與講義頁籤支援對應 placeholders，標題頁排除及預覽與匯出結果一致。

### P1：方程式入口插入一般文字方塊，且插入區沒有「符號」

**Office 預期與證據。** [nativeUI] 在本版 PowerPoint 新建空白簡報 `/private/tmp/SlidesMacAuditScratch.pptx`，步驟為 Insert → Equation。空白投影片時 Insert → Symbols 群組的 Symbol 按鈕呈 disabled；Equation 可用。按 Equation 後投影片出現「在這裡鍵入方程式」原生輸入框，並切換到 Equation 情境索引標籤；其工具列有 LaTeX → 數學式、數學式 → LaTeX、Professional、Linear、Text 切換、Equation Symbols 圖庫，以及分數、上下標、根號、積分、大型運算子、括弧、函數、加強記號、極限與對數、運算子、矩陣 11 類結構入口。圖庫 AX 顯示 188 個項目，第一頁顯示 0–100 並有「下一個方程式符號圖庫」控制。此 UI 確認 PowerPoint Mac 有原生結構方程式編輯器。Symbol 在文字游標情境是否啟用，以及 Symbol 對話框欄位，尚未捕獲。此次 CUA 在展開分數圖庫後失去視窗幾何（0×0），無法在 PowerPoint 原生 scratch 中保存／重開 Equation。另一次 GenOffice Electron E2E 已插入並保存 Equation，檢查 PPTX XML 確認是文字方塊，但沒有關閉再重開此 Equation 檔；兩者是不同應用的證據範圍。[官方 Mac] Word for Mac 的 Symbol 文件僅可作為 Word 範例，不能單獨證明 PowerPoint Symbol 對話框欄位；Math AutoCorrect 的官方適用版本包含 PowerPoint for Microsoft 365 for Mac。[Word for Mac 符號說明](https://support.microsoft.com/en-us/word/insert-a-symbol-1)、[Math AutoCorrect 適用版本](https://support.microsoft.com/en-au/accessibility/word/quick-start-guide-to-math-autocorrect-commands-and-symbols)。

**GenOffice 實際行為。** [程式碼] 插入頁「符號」群組只有 Equation 按鈕，沒有 Symbol 按鈕。方程式對話框為 12 個 Unicode 文字範本加一個自由文字欄；`insertEquation` 呼叫 `addElement({ kind: 'textbox' })`，內容是一個 28pt、斜體、Cambria Math 的普通文字 run。這是可編輯的文字方塊，不是帶結構節點的方程式物件；範本中的 Unicode 分數／上下標等只是字元排版，不能用方程式工具選取佔位區或改成其他結構。英文介面標籤已明確寫出「Equation text (Unicode math symbols, inserted as a math-font text box)」，有正確說明此降級是數學字型文字方塊；因此差異在於沒有 PowerPoint 原生結構式 Equation editor，不是沒有告知使用者。GenOffice 也沒有從文字插入點放置字元的 Symbol 對話框。

這項結論只針對 GenOffice 新的 Equation 入口。PPTX engine 另能辨識並保留開啟文件中已有的原生 OMML 方程式：`parse.ts` 將 `a14:m`／OMML 區塊保留為 run 的 `rawXml`，`generate.ts` 在編輯周圍文字時可原樣寫回。既有 `equation-table.test.ts` 兩項測試涵蓋直接 OMML 解析與鄰接文字修改後 XML 保留；這不會把 GenOffice 新插入的普通文字方塊轉成方程式物件。

**實作驗收。** 新增一種可建立、再次編輯並往返保存的結構式方程式物件；分數、根號、上下標、積分／大型運算子、矩陣、括弧、函數、運算子與符號可由結構／符號選單加入並替換佔位區。現有 Unicode 文字方塊入口及其清楚的降級標籤應保留。PowerPoint for Mac 的 Symbol 對話框欄位及插入模式需以本版實機驗證後列為產品驗收；若提供字型／字元選取，插入應在目前文字游標並保留相鄰格式、Undo／Redo 與 save/reopen 語意。

### P1：有投影片母片編輯，但母片格式工具範圍不足

**GenOffice 實際行為。** [程式碼] 有 Slide Master 檢視，列出一個 slide master 與其 layouts；可拖曳／縮放、編輯文字、改填滿及外框、刪除。此檢視獨立渲染，沒有 Home/Shape Format 功能區，右鍵只提供改文字、填滿、外框和刪除；因此無法從該檢視用母片操作改 footer 字型、段落／行距、文字填滿等完整屬性。程式碼沒有 Notes Master／Handout Master 編輯檢視。它並非「完全沒有投影片母片」：常用位置、文字、填滿、外框已有功能，既有引擎測試證明母片文字顏色及版面 placeholder 幾何可存檔重開。
