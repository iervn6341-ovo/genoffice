# Slides 列印選項評估（2026-10-16）

決定：macOS 一律直接進系統列印面板（含預覽）；Windows/Linux 維持內建列印對話框（有預覽）。
比對基準：PowerPoint（Windows 365 / Mac 16.x）列印選項（依公開功能清單與既有實作比對；未貼任何私人內容，Windows 版未實測）。
