# Sheets equation and symbol implementation — 2026-10-13

## Result

Sheets now inserts a structured Office equation drawing instead of a rasterized equation picture. The XLSX gateway writes an `xdr:sp` text shape in an `mc:AlternateContent` `a14` choice with native `a14:m/m:oMath` content. A plain text shape is the fallback for consumers without the extension. The exact author LaTeX is stored as a shape description with a SHA-256 digest of the OMML; the digest is an editing hint, not the Office equation. The gateway recomputes OMML from LaTeX and rejects a mismatched pair before saving.

The main process reads drawing parts after the sidecar has assigned anchor indices. It recognizes both the AlternateContent form and a direct `a14:m` shape, then returns an equation visual to the renderer. Original LaTeX is trusted only when its metadata digest matches the native OMML **and** converting that LaTeX reproduces the OMML; otherwise the editor derives fresh source with the strict reverse converter. Unsupported OMML, equations with more than one native math zone, and equations with picture or ambiguous text fallbacks remain visible but read-only. The writer applies the same source checks and rejects these unsafe edits. The sidecar binary and Rust parser were not changed; its existing generic shape locator supplies the anchor index and the main process interprets the extension.

An equation-only file edit now passes the preload save validator without needing an anchor move; the validator checks the LaTeX and OMML bounds before IPC. A quick pointer release also clears the global drag flag when React has not yet committed drag state, allowing the edited visual to reinstall. The gateway edits imported equations in place: it changes the native OMML and only the unambiguously matched text fallback, preserving shape name/title/custom description, transforms, geometry, fills, lines, paragraph settings, and other text runs. Its own source metadata is updated; custom descriptions are retained. Direct `a14:m` shapes remain direct. A picture fallback cannot be regenerated faithfully, so its equation is shown read-only before editing and the writer also rejects an edit. Function-based XML replacement retains literal dollar sequences.

The dialog uses the shared MathWorkbench: eleven structure groups, selection-aware templates, math symbol gallery, and professional/linear preview. New and reopened equations render from OMML as MathML. A selected equation can be re-edited from Insert Equation, double-click, right-click, Enter, or F2. Equation body pointerdown keeps the native two-click sequence intact, while MathML descendants leave the editable host as the stable hit target; resize handles retain the existing drag path. Unrelated drawing anchors remain byte-identical in the focused test. Session additions and reopened file equations both use the existing visual journal and save/undo path.

The Symbol dialog now uses the shared picker with font, subset, search, Unicode code point, and recent symbols. Picking a symbol appends it to the existing cell content as a rich-text run with the selected font, leaving earlier text and rich runs in place. The saved XLSX contains a separate `rFont` on the new symbol run. The active cell's composed font style is resolved before a plain cell becomes rich text, including when `s` is a style ID. Its existing text gets an explicit base-style run; the new symbol inherits the latest run's size, weight, color, and other font properties while using the selected font family. After a rich-text cell reopens, Univer can expose a null scalar value while retaining the document body; symbol insertion derives the scalar from the rich document stream and normalizes paragraph breaks to newlines, so a second appended symbol does not discard the prior text. Existing formula-cell behavior still replaces the calculated display value when a symbol is inserted into it; that follows the prior append workflow and needs explicit product treatment if formula editing is required.

All twenty Sheets locale shards contain localized math and symbol controls. Shared control labels reuse the corresponding Docs translations; the Sheets-specific unsupported-edit warning and equation status messages are translated in each shard. Math and symbol chrome uses the shared semantic tokens.
