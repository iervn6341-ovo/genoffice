# Sheets 列印選項評估（2026-10-16）

決定：macOS 全部走原生列印面板（含預覽）；macOS 以外開 GenOffice 內建列印對話框（`PrintDialog.tsx`），並依 Excel 列印頁面補齊選項。

## macOS 列印範圍入口（原生面板沒有「列印什麼」）

| 入口                         | 行為                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| 檔案 → 列印… (⌘P)            | 作用中工作表（原有）                                             |
| 檔案 → 列印整本活頁簿…       | `scope: workbook`，所有可見工作表分段合併成一份 PDF 後進原生面板 |
| 檔案 → 列印選取範圍…         | `scope: selection`；無選取範圍時顯示錯誤提示（toast＋狀態列）    |
| 檔案 → 列印（忽略列印區域）… | 作用中工作表、`ignorePrintArea`，印整個已使用範圍                |
| Backstage → 列印             | 在 macOS 展開窗格，列出上述四項；非 macOS 維持直接開內建對話框   |

## Excel 選項對照

圖例：對話框＝內建對話框已有；版面＝版面配置分頁已有；缺少；N/A；本次＝本次實作。
「僅列印」＝只影響本次列印與預覽，不寫回 XLSX（xlsx-gateway 與 Rust 引擎目前只存預設邊界、方向、紙張、縮放、格線、標題、頁首頁尾；custom 邊界、置中、頁序、起始頁碼等都未支援，需改 gateway 與 xlsx-engine 的 schema 與寫回，風險較高，列為後續）。

| 選項                                                      | 狀態                                 | 備註                                                                                                 |
| --------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 份數、印表機、單／雙面、逐份列印                          | 對話框（既有）                       | `PrinterSettingsFields`；macOS 由原生面板提供                                                        |
| 列印使用中工作表／整本／選取範圍                          | 對話框（既有）；macOS 新增選單入口   | 見上表                                                                                               |
| 忽略列印區域                                              | 對話框（既有）；macOS 新增選單入口   |                                                                                                      |
| 頁碼從／到                                                | 對話框（既有）                       | 整本時停用                                                                                           |
| 方向、紙張大小                                            | 對話框／版面（既有）                 | 寫回 XLSX                                                                                            |
| 邊界預設（一般／寬／窄）                                  | 對話框／版面（既有）                 | 寫回 XLSX                                                                                            |
| 自訂邊界（上下左右、頁首頁尾）                            | 本次：僅列印                         | 選「自訂邊界」顯示 6 欄（吋，0–3）                                                                   |
| 水平置中／垂直置中                                        | 本次：僅列印                         | 水平：整張表縮成內容寬並置中；垂直：單頁內可容納的區域置中，超過一頁的不動（不套用於分段大型工作表） |
| 縮放（無縮放／整頁／所有欄／所有列／自訂／N 頁寬 M 頁高） | 對話框（既有）                       | 寫回 XLSX                                                                                            |
| 列印標題（頂端列）                                        | 版面（既有）                         |                                                                                                      |
| 列印標題（左側欄）                                        | 缺少，不做                           | 引擎沒有水平分頁，無意義                                                                             |
| 列印格線、列欄標題                                        | 對話框（既有）                       |                                                                                                      |
| 頁面順序（先列後欄／先欄後列）                            | N/A，不做                            | 目前列印為單欄流動，沒有水平分頁；待引擎支援分頁後再做                                               |
| 註解與註記（不列印／工作表末／如同顯示）                  | 缺少，不做                           | 註解資料分散於 note 與 threaded comment，版面尚需設計                                                |
| 儲存格錯誤顯示為（顯示／空白／--／#N/A）                  | 本次：僅列印                         | 依顯示字串比對錯誤值                                                                                 |
| 草稿品質                                                  | 本次：僅列印                         | 不印格線與圖形（圖表、圖片、圖案）                                                                   |
| 單色列印                                                  | 本次：僅列印                         | 文字黑、移除填色、邊框黑、圖形灰階                                                                   |
| 頁首頁尾（含第一頁不同、奇偶頁不同）                      | 對話框按鈕開啟頁首頁尾對話框（既有） | 寫回 XLSX                                                                                            |
| 起始頁碼                                                  | 本次：僅列印                         | `&P` 加偏移（沿用 `data-genoffice-page-offset`）                                                     |
| 列印範圍設定                                              | 版面（既有）                         |                                                                                                      |

## 實作位置

- `apps/sheets/src/renderer/print-options.ts`：選項型別與純函式。
- `print-html.ts`：套用錯誤顯示、置中、單色、起始頁碼；`page-layout-actions.ts`：邊界覆寫、草稿去圖形、`PrintScopeOptions.options`。
- `PrintDialog.tsx`：UI；預覽 key 含選項，預覽與實際列印共用同一份 payload。
- 單元測試：`apps/sheets/tests/print-only-options.test.ts`。
