# Sheets formula-cell Symbol insertion — implementation (2026-10-13)

The Symbol command now edits formula **source** when the selected cell has a formula. The dialog shows the complete formula in an editable field. Picking a glyph replaces the field's current selection, including a caret/selection captured from Univer's live cell editor before the Symbol button can change focus. A selected formula cell with no editor open starts at the end of its source and lets the user move the caret before picking. Apply writes the edited source to the captured sheet and cell as a formula; Cancel leaves the original saved formula untouched. If Symbol opens from a live formula edit, Cancel discards that unsaved edit, like Esc in the cell editor; the source remains available in the dialog until Cancel is pressed. The chosen font is a visual picker choice only for formulas, because Excel formula text does not store character-level font runs.

The write is one normal Univer `SetRangeValues` action, with explicit `v`, `p`, and `si` nulls to remove the old calculated result, rich document, and shared-formula group. That action remains undoable and enters the existing edit journal/XLSX `<f>` save path. The target workbook/sheet/cell is fixed when the dialog opens, so a background selection change cannot redirect Apply. The ordinary symbol action refuses formula cells instead of converting their displayed result into rich text. If an ordinary text cell is being edited, Symbol first captures its workbook/sheet/cell, awaits a normal editor commit, then opens the existing rich-symbol picker; the new glyph appends to the freshly committed text in that captured cell. This matters because Univer's Enter commit advances the active range to the next row.

The Univer APIs checked for this path are `IEditorBridgeService` (editing state and current document unit), `DocSelectionManagerService` (source caret/selection), `DocumentDataModel` (live source), and the FRange `setValue`/`setFormula` facade. The latter forwards an `ICellData` object unchanged, which is why this implementation explicitly clears stale `v`, `p`, and `si` instead of supplying only `f`. The Symbol button suppresses pointerdown focus transfer so the live selection still exists when the command handler captures it. On narrow ribbons, the folded Symbols launcher has the same opt-in focus preservation; other folded groups retain their existing behavior. The modal opens only after a successful editor abort for formulas or successful editor commit for plain text.
