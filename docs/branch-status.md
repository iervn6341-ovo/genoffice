# 開發分支狀態

本文件描述 Electron 分支目前的工作範圍與尚待完成的驗收。上游持續變動；README 的比較以指定 upstream commit 為時間點，不能取代逐項原始碼比對。

## 已有工作

- Docs：目錄及欄位、頁碼、符號與方程式、字型替代、外部變更處理及文件相容性。
- Sheets：公式快取、儲存與重開、外部活頁簿連結與參照、格式和大型檔案效能。
- Slides：頁碼及方程式、動畫、文字與物件編輯、備忘錄、多視窗及 PowerPoint 相容性。
- Shell：多視窗分頁、主題同步、AI 設定檔、自訂供應商、最近檔案與檔案變更通知。
- PDF 與 Markdown：空白 PDF 生命週期、頁面操作、Markdown 雙向連結與圖譜相關功能。

## 尚待工作

- 比對並整合最新上游的功能與安全修正，確認沒有回退或重複實作。
- 舊版 `.doc` 轉換仍在開發：2026-11-18 測試有 4 項失敗，涉及大小寫、字型屬性及目錄超連結樣式。
- 2026-11-18 回歸：CLI 2 項（頁首頁尾欄位文字及儲存格填色）、Docs 4 項（文字方塊編輯／拖曳與樣式庫展開）、Shell 2 項（MCP 格式登錄）測試失敗，需釐清是實作問題或測試期望過時。
- 以實際 Word、Excel、PowerPoint 檔案持續驗證格式、複雜物件及雙向儲存。
- 對大型文件、視窗快速調整及跨平台行為持續量測與回歸測試。
- macOS 原生拖曳目前有補救機制；使用者初步回饋正常，但原生失效根因與長時間穩定性仍待確認。
- Swift／Rust 移植進度和規劃見 [重構計畫](architecture/swift-rust-refactor-plan.md)；該計畫不代表全部功能完成。

測試和 Office 實機驗證應分別記錄，不以單元測試宣稱完整相容。歷史 QA 文件及原始上游文件保留作追溯；本次不加入本機臨時診斷輸出或個人文件。
